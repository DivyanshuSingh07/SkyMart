# SkyMart

SkyMart is a modern e-commerce web application built with React, Vite, and Context API. It provides a premium shopping experience with features like authentication, product browsing, wishlist management, cart functionality, checkout flow, multiple themes, and a responsive UI.

![SkyMart Banner](./public/banner.png)

---

## Features

### Authentication

- User Registration
- User Login
- Auto Login Support
- Persistent User Sessions using Local Storage

### Shopping Experience

- Browse Products
- Product Details Page
- Search Products
- Filter Products by Category
- Sort Products by Price
- Pagination Support

### Cart System

- Add to Cart
- Remove from Cart
- Increase/Decrease Quantity
- Real-Time Cart Calculations
- Cart Drawer
- Sticky Order Summary

### Wishlist

- Add Products to Wishlist
- Remove Products from Wishlist
- Dedicated Wishlist Page

### Checkout

- Shipping Information Form
- Multiple Payment Methods
  - Card
  - UPI
  - Cash On Delivery
- Dynamic Order Summary
- Order Placement Notifications

### UI Enhancements

- Dark Theme
- Light Theme
- Cyber Neon Theme
- Midnight Blue Theme
- Royal Purple Theme
- Animated Toast Notifications
- Responsive Design
- Premium Footer
- Hover-Based Theme Panel

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/skymart.git
```

Move into the project directory:

```bash
cd skymart
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
